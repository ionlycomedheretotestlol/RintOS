# RintOS 1.4.2

**Install:** download `RintOS-1.4.2.apk` and install it over 1.4.x (your setup stays). To watch the intro: Settings → Permissions → Replay the intro.

## Changed
- **The intro now shows only pixel Rin.** Every scene (the power-up, the demos, the stars, the concert) uses 8-bit Rin, whatever Rin style you picked.

Everything from 1.4.1 (the "Rin's Upgrade Day" intro, the new startup screen, notch sound fixes) is included.
